# 📔 Diario

Aquí van las notas diarias. Cada nota de diario tiene una sección por rama (TAI, HAM, ZEN, CEO) — escribe ahí qué hiciste ese día en cada una, enlazando a la nota que corresponda (ej: "Practiqué [[Ingles]] 30 min"). Así el diario se vuelve el hilo que conecta todas tus ramas día a día.

## Cómo activarlo (una sola vez)
1. Settings ⚙️ → Core plugins → activa **"Daily notes"**
2. En sus opciones (Settings → Daily notes):
   - Date format: `YYYY-MM-DD`
   - New file location: `05-Diario`
   - Template file location: `99-Plantillas/Plantilla - Diario`
3. Desde ahora, el ícono de calendario 📅 en la barra izquierda crea/abre la nota de hoy ya con las 4 secciones listas
