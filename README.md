# 🤖 Mi Claude Personal — Jeffdevops66

Sistema personalizado de skills, comandos y agentes para maximizar Claude Pro.

## ⚡ Comandos disponibles

| Comando | Qué hace |
|--------|----------|
| `/last30days` | Analiza los últimos 30 días de cualquier proyecto o negocio |

## 🧠 Skills (Modos especiales de Claude)

| Skill | Cuándo usarlo |
|-------|--------------|
| `mi-negocio` | Análisis y estrategia de negocio personal |
| `investigador` | Investigar temas, competidores, mercados |
| `redactor` | Crear contenido, posts, emails, anuncios |
| `estratega` | Planes de acción 30/60/90 días |

## 🚀 Cómo instalar en cualquier computadora

```powershell
git clone https://github.com/Jeffdevops66/mi-claude-personal.git
Copy-Item "mi-claude-personal\commands\*" "$env:USERPROFILE\.claude\commands\" -Force
Copy-Item "mi-claude-personal\skills\*" "$env:USERPROFILE\.claude\skills\" -Force
```
